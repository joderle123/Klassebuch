App hinzufügen

Jede App bleibt eine eigene Datei — der Hub zeigt sie nur an. An der App selbst musst du nichts ändern, und ihre Daten bleiben dieselben, ob du sie im Hub oder direkt öffnest.

1
Datei ablegenDie App-Datei in denselben Ordner wie hub.html legen — übersichtlicher in einen Unterordner apps/.
2
Eintragenhub-apps.js öffnen, den Vorlage-Block kopieren und Name, Icon, Farbe, Bereich und Pfad anpassen.
3
Neu ladenhub.html mit Strg + F5 neu laden. Die App erscheint als Kachel und im Menü.

Die Vorlage

So sieht ein Eintrag in hub-apps.js aus. Kopiere ihn innerhalb der eckigen Klammern [ … ] unter die bestehenden Apps:

{
  id: 'meine-app',
  name: 'Meine App',
  beschreibung: 'Wofür die App gut ist — ein Satz.',
  icon: '🧩',
  farbe: '#c0562d',
  bereich: 'Team & Organisation',
  datei: 'apps/meine-app.html'
},   ← dieses Komma nicht vergessen
⚠️
Häufigster Fehler: das Komma nach } oder ein fehlendes Anführungszeichen. Der Hub merkt das und zeigt dir oben in der Übersicht eine Warnung, statt einfach leer zu bleiben.

Welche Art von App hast du?

A · Eine einzelne HTML-Datei funktioniert sofort

Wie das Klassenbuch oder SAVOIR: eine .html-Datei, die man per Doppelklick öffnet. Einfach ablegen und mit datei: 'apps/name.html' eintragen — fertig.

B · Eine React- oder Vite-App einmal umbauen

Wie PaedPath: ein Projekt mit package.json, das mit npm run build gebaut wird. Ein normaler Build erzeugt einen Ordner mit ausgelagerten Programmteilen — und die blockiert Edge bei lokalen Dateien, die App bleibt dann weiß. Die Lösung ist, sie als eine einzige Datei zu bauen:

  1. Im App-Ordner einmal ausführen: npm install -D vite-plugin-singlefile
  2. In vite.config.ts das Plugin ergänzen (siehe unten).
  3. npm run build ausführen.
  4. Die Datei dist/index.html umbenennen (z. B. in paedpath.html), in den Ordner apps/ legen und wie bei Weg A eintragen.
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'
import { viteSingleFile } from 'vite-plugin-singlefile'   // neu

export default defineConfig({
  plugins: [react(), tailwindcss(), viteSingleFile()],   // viteSingleFile() neu
  base: './',
})
ℹ️
PaedPath nutzt bereits einen HashRouter — das passt, die Seitenwechsel funktionieren auch im Hub. Achtung: Im Repository liegt nur ein Teil des PaedPath-Quellcodes. Bauen musst du dort, wo das vollständige Projekt liegt.

C · Eine Webseite oder ein Online-Dienst öffnet im neuen Tab

Zum Beispiel ein Schulportal, Teams oder SharePoint. Statt datei trägst du link: 'https://…' ein. Solche Seiten öffnen sich in einem neuen Tab, weil die meisten Webseiten das Einbetten in andere Seiten verbieten.

Alle Felder im Überblick

FeldBedeutungBeispiel
idKurzer Name ohne Leerzeichen, einmalig. Wird für Links genutzt.'savoir'
nameAnzeigename auf Kachel und im Menü.'SAVOIR'
beschreibungEin Satz: wofür ist die App gut?'Klinisches Wissen …'
iconEin Emoji. Unter Windows: Windows-Taste + Punkt.'📚'
farbeAkzentfarbe der Kachel, als #rrggbb.'#b8892d'
bereichGruppe im Menü. Apps mit gleichem Bereich stehen zusammen.'Wissen & Materialien'
dateiPfad zur App-Datei, von hub.html aus gesehen.'apps/savoir.html'
linkStatt datei: Adresse einer Webseite.'https://…'
hinweisOptional. Kurzer Hinweis auf der Kachel.'Wird noch gebaut'
stichworteOptional. Weitere Suchbegriffe für das Suchfeld.'diagnose methode'

Eine App ohne datei und ohne link erscheint als geplant — praktisch, um schon einen Platz für eine App zu reservieren, die noch nicht fertig ist.

Wenn etwas nicht klappt

Die Übersicht zeigt „App-Verzeichnis fehlerhaft"

In hub-apps.js ist ein Tippfehler — fast immer ein fehlendes Komma nach } oder ein fehlendes Anführungszeichen '. Die genaue Stelle zeigt dir Edge: F12 drücken, Reiter Konsole. Dort steht rot etwa hub-apps.js:63 — der Fehler steckt in dieser Zeile oder direkt davor. Vergleich deinen Eintrag dann Zeichen für Zeichen mit der Vorlage.

Die App bleibt weiß

Fast immer eine React/Vite-App mit normalem Build. Baue sie als Einzeldatei (Weg B).

Edge zeigt „Datei nicht gefunden"

Der Pfad in datei stimmt nicht. Prüfe Ordnername, Dateiname und Groß-/Kleinschreibung. Der Pfad gilt von hub.html aus: liegt die App in apps/, lautet er 'apps/name.html'.

Sind meine Daten im Hub andere als sonst?

Nein. Getestet: Eine App sieht im Hub genau dieselben Daten wie direkt geöffnet — solange du im selben Browser auf demselben Gerät arbeitest. Die Daten liegen im Browser, nicht in der Datei. Deshalb siehst du sie auf einem anderen PC nicht automatisch.

Eine Webseite lässt sich nicht einbetten

Viele Webseiten verbieten das aus Sicherheitsgründen. Trag sie mit link statt datei ein — dann öffnet sie sich in einem neuen Tab.
